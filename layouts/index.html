What is go-odf?

go-odf converts ODT ⇄ richdoc in pure Go, CGO-free: an OpenDocument file becomes the shared document model, and the model becomes an ODT a word processor will open. It reads the other bodies too — .ods spreadsheets, .odp presentations and .odg drawings — because they are the same ZIP of XML with a different body element, and walking only office:text parsed each of them into a document of nothing, without an error.
